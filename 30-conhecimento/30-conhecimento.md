# Conhecimento

Raiz comum a todos os projetos (P8). `raw/` = fontes originais, o Jarvis não escreve aí. `wiki/` = o compilado pelo `/wiki-ingest`, com citação de cada afirmação. `marketing/`, `copy/`, `atendimento/` = conhecimento que serve a mais de um projeto; as notas de projeto apontam para cá em vez de copiar.

## Notas
- `raw/` — vazio (a EducaBet entra na Fase 2)
- `wiki/` — vazio
- `marketing/`, `copy/`, `atendimento/` — vazios (Fase 4)

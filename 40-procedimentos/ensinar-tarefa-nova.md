# Ensinar uma tarefa nova ao Jarvis

1. Fazer junto a primeira vez, testar e corrigir.
2. Gravar em [[licoes]] o que funcionou, o que não funcionou e as pegadinhas.
3. Escrever o procedimento aqui em `40-procedimentos/` (modelo [[procedimento]]), com **Leia antes** e **Pausa obrigatória**, e pôr no índice.
4. O que for só conta (comparar números, conferir datas) vira script sem IA num timer, que só chama o Jarvis quando houver algo (P6) — proposta para você aprovar, com o script lido antes.
